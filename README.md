# DuckDuck Club — Landing Page

## Setup

```bash
npm install
npm run dev
```

## Deploy

Push to GitHub → Vercel auto-deploys.

## Images

- `logo.png` — Club logo
- `founder-photo.jpg` — Founder photo
- `club-screen-1.png` — Community screenshot 1
- `club-screen-2.png` — Community screenshot 2
- `club-screen-3.png` — Community screenshot 3
